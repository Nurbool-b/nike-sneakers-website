# Nike Landing Page (Planet Store)

## Құрылымы
```
index.html      — негізгі HTML разметкасы
styles.css      — барлық стильдер (CSS)
script.js       — интерактивтік логика (JS)
assets/         — суреттер (кроссовка түстері + иллюстрациялар)
```

## VS Code-та қалай ашу керек

1. Осы қалтаны (`nike-site` немесе қалай атасаңыз да) **File → Open Folder...** арқылы VS Code-та ашыңыз.
2. `index.html` файлын ашып, оң жақ төмендегі **"Go Live"** батырмасын басыңыз
   (алдымен **Live Server** кеңейтімін орнату керек: Extensions → іздеу "Live Server" → Install).
3. Немесе жай ғана `index.html`-ды браузерде екі рет басып ашуға болады — суреттер салыстырмалы жол арқылы (`assets/...`) жүктеледі, сондықтан бүкіл қалта бірге болуы керек.

## Не істейді

- **Кроссовканы басу** — 3 түс арасында ауысады (Court Purple → Varsity Red → Total Orange), видеодағыдай "секіріп түсу" анимациясымен.
- **"Оформить заказ"** — тапсырыс секциясына scroll жасайды, форма толық жұмыс істейді (валидация + растау хабары).
- **"В тренде" pill-дер және "Подробнее" батырмалары** — әр кроссовка моделі туралы ақпараттық терезе (модаль) ашады, Nike-дың ресми тарихымен.
- **Мобильді бейімдеу** — барлық секциялар телефон экранына (≤680px, ≤420px) бейімделген.

## Файлдарды өзгерту

- Түстер мен мәтіндерді өзгерту үшін `styles.css` және `index.html`.
- Кроссовка ауысу логикасы, форма, модаль — барлығы `script.js` ішінде.
- Жаңа түс қосу үшін `assets/` қалтасына жаңа PNG қосып, `script.js`-тегі `THEMES` массивіне жазба қосыңыз.
